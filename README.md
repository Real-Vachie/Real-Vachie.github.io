# real-vachie.github.io

Root of the GitHub Pages domain: **Vachie's portfolio page** (`index.html`, images in `media/`; Soot & Summer pictures load from `/soot-and-summer/media/`).
It also holds `/.well-known/assetlinks.json` so Android App Links work for Soot & Summer visit links (it must sit at the domain root).
`.nojekyll` is needed, or Pages would hide the `.well-known` folder.
